# Kyberbezpečnost – Modul 12 (ECDL/ICDL)

Statická česká prezentace pro 5 vyučovacích hodin (225 minut bez přestávek).
Otevřete index.html. Bez instalace a buildu. Hlavní cvičení fungují offline;
externí nástroje a Google Fonts potřebují internet (fonty mají místní náhrady).

## Obsah
- index.html: výklad, původní náhledy služeb, modelový e-mail, kvízy, řešení a slovníček.
- images/: ilustrativní náhledy externích služeb.
- exercises/obnova.txt: neosobní data pro cvičení zálohy a obnovy.
- LEKTOR.md: časový plán, příprava a návaznost na sylabus.

## Ovládání
Šipky, mezerník, PageUp/PageDown; Home/End; O = osnova. Osnova obsahuje
přímý vstup do slovníčku. Escape osnovu zavře. Tlačítka a rozbalovací řešení
lze ovládat klávesnicí. Dotykové gesto přepne slajd mimo ovládací prvky.
Kvíz lze zkusit opakovaně; odpovědi se nikam neodesílají ani neukládají.
Obnovení stránky vrací prezentaci na začátek. Tisk vynechává volitelné ukázky.

## Nasazení
Nahrajte index.html, images/ a exercises/ na statický hosting nebo GitHub Pages.
V GitHub Settings → Pages vyberte příslušnou větev a kořenovou složku.

Zobrazení využívá celou plochu okna a přizpůsobuje velikost textu každému slajdu. Tlačítko Celá obrazovka nebo F zapne režim bez lišt prohlížeče; Escape jej ukončí. Na malých obrazovkách a u delšího rozbaleného obsahu lze posouvat slajd.
